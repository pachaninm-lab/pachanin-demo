## Team rule

Before starting any new delivery slice, both work contours must:
1. re-fetch current `main`;
2. read the Team Hub and latest coordination messages;
3. inspect the other contour's active PRs and changed paths;
4. inspect dependency/handoff requests;
5. read the applicable MASTER sections here;
6. claim a non-overlapping slice before implementation.

Live coordination is tracked in the PC-CROP Team Hub issue. This branch/file set is intentionally not merged merely to communicate coordination state, because moving `main` for coordination alone can invalidate exact-current-main production evidence.
