# Contribution IP Policy

A contribution may be merged only when the contributor has the right to submit
it and can identify any third-party material contained in it.

Forbidden without explicit IP/legal approval:

1. Copying source, templates, assets or documentation from an external repository
   without recording source, version/commit and license.
2. Removing or altering third-party copyright/SPDX/license notices to conceal
   provenance.
3. Introducing AGPL/GPL/SSPL or unknown/custom licensed runtime material without
   review.
4. Publishing internal `@pc/*` or `@pachanin/*` packages.
5. Moving protected proprietary-core code into browser-public/static artifacts.

AI-assisted contributions are reviewed under the same rules. A model-generated
snippet is not presumed clean merely because no source URL is known.

Required evidence for externally sourced material:

- source URL/repository and immutable revision;
- original author/rightsholder when stated;
- license/SPDX identifier or full license text;
- files incorporated or adapted;
- reason for use and approval record.

Every new or materially modified product file must also record a known origin,
first-party/infrastructure/integration classification, resolved license,
dependency approval where applicable, security review and provenance evidence.
An unresolved origin or restrictive product/runtime license blocks merge.
