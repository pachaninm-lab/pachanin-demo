# Конфигурация Гекты

Все значения задаются в production-окружении виртуального сервера REG.RU.
Файл `.env.example` намеренно не редактируется: `scripts/p7-autopilot-guard.sh`
запрещает изменение любых `.env*` путей, и это ограничение не ослабляется ради
документации.

Ни одна из переменных ниже не является секретом продукта, кроме явно отмеченных.

## Модель доступа

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEKTA_ANONYMOUS_SESSION_SECRET` | *(нет)* | **Секрет.** Ключ подписи анонимной сессии свободного режима. Без него сервер подписывает ключом, живущим в памяти процесса, и счётчик бесплатных ответов сбрасывается при рестарте. В production задать обязательно, минимум 16 символов. |
| `GEKTA_ANONYMOUS_FREE_ANSWERS` | `10` | Сколько завершённых ответов доступно без регистрации. |
| `GEKTA_TRIAL_DAYS` | `30` | Длительность пробного доступа после регистрации, в днях. Считается по серверным часам. |
| `GEKTA_MONTHLY_PRICE_RUB` | `299` | Цена месячной подписки. Отображается пользователю и используется при создании платежа. |
| `GEKTA_PAID_FAIR_USE_ANSWERS_PER_DAY` | `300` | Потолок разумного использования платного тарифа. Тариф никогда не называется безлимитным. |
| `GEKTA_REGISTRATION_URL` | *(нет)* | Путь входа в регистрацию Гекты, начинающийся с `/`. Пока не задан, gate показывает продукт и поддержку вместо кнопки регистрации. |

## Персональные данные

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEKTA_PHONE_ENCRYPTION_KEY` | *(нет)* | **Секрет.** Ключ шифрования канонического номера телефона (AES-256-GCM), base64 или hex, 32 байта. Без него регистрация с телефоном отключена. |
| `GEKTA_PHONE_LOOKUP_PEPPER` | *(нет)* | **Секрет.** Перец для HMAC-индекса поиска по точному номеру. Отдельный от ключа шифрования, чтобы компрометация индекса не раскрывала номера. |

## Верификация телефона

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEKTA_PHONE_VERIFICATION_PROVIDER` | `NONE` | `NONE`, `SMS`, `FLASH_CALL` или `OTHER_VERIFIED_CHANNEL`. При `NONE` телефон остаётся обязательным атрибутом аккаунта в состоянии `DECLARED`, и продукт никогда не называет его подтверждённым. |

## Биллинг

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GEKTA_BILLING_ENABLED` | `false` | Приём платежей. Включается только когда одновременно выполнены условия готовности из `docs/gekta/legal-source-audit-*.md`: подтверждённый профиль продавца, договор с провайдером, работающая выдача чека. |
| `GEKTA_PAYMENT_PROVIDER` | `NONE` | Идентификатор платёжного провайдера для provider-neutral адаптера. |
| `GEKTA_RECEIPT_PROVIDER` | `NONE` | Идентификатор провайдера фискального чека. |
| `GEKTA_MERCHANT_PROFILE_ID` | *(нет)* | Идентификатор действующего профиля продавца. Профиль версионируется: старые платежи сохраняют снимок продавца на момент оплаты. |

## Что происходит, когда переменная не задана

Продукт не показывает нерабочих элементов. Отсутствие ключа шифрования телефона,
провайдера верификации, платёжного провайдера или профиля продавца отключает
соответствующую функцию, но не ломает остальной продукт: анонимный режим,
пробный доступ и ручной доступ от владельца продолжают работать.

## Профиль продавца

Юридическая форма продавца — конфигурация. Пока `GEKTA_MERCHANT_LEGAL_NAME`
не задан, профиль считается незаполненным: документы не показывают выдуманных
реквизитов, а приём платежей выключен.

| Переменная | Назначение |
| --- | --- |
| `GEKTA_MERCHANT_OPERATOR_TYPE` | `NPD_INDIVIDUAL` (по умолчанию), `IP` или `LEGAL_ENTITY`. Определяет формулировки в документах и режим чека. |
| `GEKTA_MERCHANT_LEGAL_NAME` | Наименование продавца в документах. Пустое значение = профиль не заполнен. |
| `GEKTA_MERCHANT_FULL_NAME` | ФИО для физлица и ИП. |
| `GEKTA_MERCHANT_INN` | ИНН. |
| `GEKTA_MERCHANT_OGRNIP` / `GEKTA_MERCHANT_OGRN` | Регистрационные номера, если применимы. |
| `GEKTA_MERCHANT_LEGAL_ADDRESS` / `GEKTA_MERCHANT_CONTACT_ADDRESS` | Адреса — только там, где закон требует. |
| `GEKTA_MERCHANT_SUPPORT_EMAIL` / `GEKTA_MERCHANT_SUPPORT_PHONE` | Контакты для потребителя. |
| `GEKTA_MERCHANT_TAX_REGIME` | `NPD`, `USN`, `OSNO`, `OTHER`. По умолчанию выводится из формы продавца. |
| `GEKTA_MERCHANT_VERIFIED_AT` | Дата фактического подтверждения реквизитов. |
| `GEKTA_MERCHANT_SOURCE` | Откуда взяты реквизиты: реестр, документ, конфигурация. |
| `GEKTA_MERCHANT_EFFECTIVE_FROM` | С какой даты действует версия профиля. Старые платежи хранят снимок продавца на момент оплаты. |
| `GEKTA_NPD_STATUS_VERIFIED` | `true` только когда фактический статус плательщика НПД подтверждён. |
| `GEKTA_NPD_ANNUAL_LIMIT_RUB` | Лимит режима НПД. По умолчанию 2 400 000. |
| `GEKTA_NPD_WARN_PERCENT` | Порог предупреждения, по умолчанию 80 %. |
| `GEKTA_SUBSCRIPTION_TERMS_PUBLISHED` | `true` только когда опубликованы условия подписки, отмены, отказа от автопродления и возврата. |

Переход `NPD_INDIVIDUAL → IP → LEGAL_ENTITY` меняет только профиль. Аккаунты,
подписки, entitlement и история не мигрируют.
